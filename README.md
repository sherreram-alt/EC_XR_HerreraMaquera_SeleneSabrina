## 1. Descripción del Proyecto
Proyecto de Realidad Virtual desarrollado en Unity utilizando Universal Render Pipeline (URP) y el paquete XR Interaction Toolkit. La escena incluye una estructura de sala con paredes y piso interactivo, objetos manipulables con físicas, interfaz de usuario con lienzo y botón, y zona de teletransporte.

---

## 2. Componentes e Interacciones Configurados
- **XR Origin (VR):** Configurado como origen del sistema XR.
- **Objetos Manipulables:** Componentes `Rigidbody` y `XR Grab Interactable` (con Colliders vinculados).
- **Interfaz de Usuario:** `UI Canvas` y `Button` interactivo.
- **Teletransporte:** Componente `Teleportation Area` asignado al piso (`Plane`).
